# МануалВидео PRO — MVP сервиса озвученных видеоруководств по ремонту авто и спецтехники

Рабочий прототип сервисной платформы, построенный на базе полного руководства **Ford Fiesta / Fusion** (`Ford_Fiesta_Fusion_TR_Carinfo.com.ua_compressed.pdf`, 385 страниц).

## Что реализовано в прототипе

1. **4 готовых HD-видеогида (MP4 1280×720) с русской дикторской озвучкой:**
   - **Замена масла и масляного фильтра ДВС** (`public/media/videos/oil-change.mp4`, 4 этапа, 14 иллюстраций, стр. 105–106)
   - **Замена передних тормозных колодок** (`public/media/videos/brake-pads.mp4`, 3 этапа, 9 иллюстраций, стр. 195–197)
   - **Замена ремня привода ГРМ Duratec 1.4 / 1.6** (`public/media/videos/timing-belt.mp4`, 2 этапа, 13 иллюстраций, стр. 73–74)
   - **Замена и обслуживание свечей зажигания** (`public/media/videos/spark-plugs.mp4`, 1 этап, 6 иллюстраций, стр. 227)

2. **Двухрежимный плеер механика:**
   - **Видеоролик с диктором (MP4):** плавный зум по оригинальным фото и векторным стрелкам мануала, панель телеметрии (инструмент, моменты затяжки в Н·м, предупреждения безопасности), кликабельные таймкоды и синхронная текстовая расшифровка речи.
   - **Пошаговый режим «Свободные руки» (для бокса/гаража/поля):** озвучка по этапам с автопаузой (видео не убегает вперед во время работы ключом), зум иллюстраций, горячие клавиши (`Пробел`, `←`, `→`, `R`) и голосовое управление через микрофон браузера (*«дальше»*, *«назад»*, *«повтори»*, *«пауза»*).

3. **Полная оцифровка книги (385 стр.):**
   - Оглавление из **16 разделов и 449 подразделов** с рендерингом любой страницы PDF в высоком разрешении;
   - Интерактивный каталог всех **62 цветных электросхем** (стр. 353–383);
   - Поиск и расшифровка **187 кодов неисправностей OBD-II** (`P`, `B`, `C`, `U`);
   - Справочник **моментов затяжки, объемов ГСМ, ламп** и интерактивная сетка **регламента ТО (20–120 тыс. км)**;
   - Мгновенный полнотекстовый поиск по всем 385 страницам книги.

4. **Витрина масштабирования B2B/B2C:**
   - Каталог легковых авто, грузовиков (`КАМАЗ-54901 К5`), строительной (`XCMG XE215C`, `JCB 3CX`) и сельскохозяйственной спецтехники (`МТЗ / John Deere`) с демонстрацией конвейера конвертации заводских PDF в озвученные видеокарты.

## Запуск

```bash
npm install
npm start
```

Сервер запускается на `http://0.0.0.0:3000`.
