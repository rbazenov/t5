# Поставщики б/у запчастей VW T5 / Caravella / Multivan

Таблица рассылки «запрос прайса» по поставщикам б/у запчастей для коммерческого
транспорта Volkswagen (T5, Transporter, Caravella, Multivan, а также T4/Crafter).

- **Источник:** папка «Отправленные» Gmail, аккаунт `prodjectmen@gmail.com`
- **Дата рассылки:** 24.10.2026, 20:24–21:20 (МСК)
- **Компаний в таблице:** 21, писем: 22 (A2Z Parts Online получил два письма)
- Плюс одно тестовое письмо себе — вынесено на отдельный лист «Служебные»

## Файлы

| Файл | Что внутри |
|---|---|
| `vw-t5-suppliers.xlsx` | Основная таблица: лист «Поставщики» + лист «Служебные», фильтры, закреплённая шапка |
| `vw-t5-suppliers.csv` | Тот же список в CSV (разделитель `;`, UTF-8 с BOM — открывается в Excel без настройки) |
| `build_table.py` | Генератор обоих файлов из списка `ROWS` (удобно дополнять новыми контактами) |

## Колонки

`№` · `Компания` · `E-mail` · `Дата и время (МСК)` · `Тема письма` · `Ответ` · `Примечание` · `ID письма (Gmail)`

- **Ответ** — пустая колонка для отметок по входящим письмам.
- **Примечание** — откуда взято название компании (из темы письма или по домену),
  повторы отправки, пометки по личным адресам.
- **ID письма** — идентификатор Gmail, по нему письмо ищется в веб-интерфейсе
  (в поиске: `rfc822msgid` нет, но можно открыть письмо по ссылке
  `https://mail.google.com/mail/u/0/#all/<ID>`).

## Что было в письме

Запрос прайса на: двигатели (1.9 / 2.5 / 2.0 TDI) и агрегаты, МКПП и АКПП,
NOS-оригинал, распилы и доноры, задние двери, крылья, капоты, двери целиком,
авто после ДТП. К письмам приложен файл `zapros_zapchastey.xlsx`.
Часть писем — на русском (тема «Запрос прайса…»), часть на английском
(тема «Request for quotation…»), для ОАЭ указана доставка в Москву.

## Как обновить

```bash
# дописать новые строки в ROWS внутри build_table.py
python3 suppliers/build_table.py
```

Требуется `openpyxl` (`pip install openpyxl`) — только для сборки `.xlsx`.
